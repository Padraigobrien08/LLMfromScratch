## Design Specificity Verdict

Authored, decisively. The "broadsheet" conceit — masthead, thick/thin rules, dateline rail carrying live measured figures, Roman-numeral plates, mono for every measured number, provenance notes naming actual test files — is a design argument, not a skin: the form encodes the site's epistemic claim that every number is measured. Zero template smell.

Deterministic scan (degraded regex fallback; contrast rules not evaluated): 2 CLI findings (`side-tab` at styles.css:1632, `transition: width` at styles.css:1683 — likely a progress fill, probably benign). Browser overlay on 5 of 17 routes: dominant real finding is **~30 instances of 10.5px UI text** from one shared caption/label token (stack-figure labels, stat-widget labels, chart labels); plus prose lines at ~90 chars (over the ~80 aim) and one recurring ~154–166-char line. The recurring 33-char all-caps hits are the intentional masthead/kicker — false positive.

## Priority Issues

1. **[P1] No failure state for the WebGL stack figure.** `mountStackFigure` in StackFigure.tsx has no catch; a blocked context or denylisted GPU leaves the landing page's dominant element blank. Fix: try/catch that swaps in the existing static SVG plate plus one line saying so. → /impeccable harden
2. **[P1] Screen-reader payload of the figure panel.** The captured accessibility tree exposes all fourteen parts' descriptions/shapes/budgets (~50 context-free strings) despite aria-hidden in JSX; hidden stacks use visibility:hidden at ≥1280. Fix: verify with real AT; render only the selected part's fields (reserve height via min-height) or use `inert`. → /impeccable harden
3. **[P2] Undersized label text, one token, ~30 sites.** 10.5px labels across the stack figure, tokenizer stats, RoPE demo, ablations chart. Below comfortable legibility and likely below WCAG-friendly sizes on dense pages. Fix: raise the caption token to ≥11–12px equivalent and let the fluid scale carry it. → /impeccable typeset
4. **[P2] First-screen redundancy + readout ambiguity.** Dateline rail and front-metrics print the same figures twice within ~40px (Front.tsx's own comment says the strip was removed for exactly this); Reproduction's scrub readout shows 3.0806 beside the headline 3.0503 with an unlabeled "THROUGH THE RUN → 100%". Fix: suppress or demote one figure row; label the readout ("val loss at cursor", "% of run at cursor"). → /impeccable clarify
5. **[P3] Naming split.** Tab/wordmark say "NanoGPT From Scratch"; repo, base path, GitHub link say LLMfromScratch. Land the documented rename sweep. → (repo task, not a design command)

## Cognitive Load

7 of 8 checklist items pass. Fail: chunking/decision-point counts — the stack figure exposes 14 clickable labels at once and the ablations strip has 12 axis chips; the front page totals ~27 clickable things above the fold. Defensible for an exploratory instrument, but the true first-impression decision surface far exceeds the ≤4 the site holds elsewhere.

## Emotional Journey

Peak: clicking a slab and getting shape + parameter share + the exact pinning test, one button from its chapter. End: chapter feet ending on the next question in italic — strong peak-end. Valley 1: first contact for a novice (27 interactive elements, no explicit "start here"; the Learn door is small type far left while the eye goes to the plate). Valley 2: below 768px the centrepiece is a static drawing and nothing says so.

## What's Working

1. Epistemic design integrity — mono = measured, provenance footers, pre-registered targets, noise floor printed before results.
2. The stack figure as navigation — the diagram doubles as the site map; every part links to its chapter and its test.
3. Craft depth — fixed panel slots, order-swapped mobile flow, reasoned fluid type scale.

## Persona Red Flags

**Jordan (first-timer):** interactivity of the plate signaled only by cursor + a small caption below the fold on short windows; the "№ 01 Learn" door loses the eye to the plate; "Plate II", "acc_norm", "MFU" reachable before definition.

**Sam (screen reader/keyboard):** hidden-copy payload (issue 2); the 14 engine-injected label buttons' tab order is engine-owned and unverified; each front-page destination has two tab stops to the same URL (6 stops for 3 choices); role="status" fires on mount before any user action.

**Casey (mobile):** static plate below 768px still renders full labels + panel with no notice that orbit is gone; chapter rail scrolls sideways with no overflow cue; 14px captions over 24ch wrap 3 lines per metric on the first screen. (Mobile from source; pane was taken over before 375px screenshots.)

## Minor Observations

- Stale comment in Front.tsx says "346 tests green"; live rail says 412.
- Footer "Where this came from · MIT · Source on GitHub" reads as one link run; "·" glue awkward for AT.
- "◟" favicon may read as dirt at 16px.
- Unknown-route fallback is silent; a one-line status would cost nothing.
- Ablations "within noise"/"worse" near the boundary would benefit from the noise floor restated in the column header.
- Source Serif 4 loads from Google Fonts — FOUT + privacy at odds with a self-contained ethos; self-host.
- Article prose runs ~90 chars/line vs the ~80 aim (detector, multiple pages).

## Questions to Consider

1. The broadsheet is authoritative and finished, but the project's charm is visible reasoning and admitted wrong predictions — should the lab notebook show through the newsprint anywhere (margins, errata line)?
2. Would a 15-second guided first pass on the figure (auto-highlight three parts on first visit) betray the print ethos or fulfil it?
3. Who is the 768–1279px reader actually getting — was that band designed or merely survived?
